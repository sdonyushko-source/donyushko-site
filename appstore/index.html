Rexi — скриншоты для App Store

Rexi — приложение знакомств для людей с собаками: свайпы, взаимные симпатии и чат, чтобы договориться о совместной прогулке. Я спроектировал интерфейс приложения и собрал набор скриншотов для его страницы в App Store.

Листается вбок · по клику открывается в полном размере

Как устроен набор

  1. Первый кадр продаёт идею целиком. Логотип, обещание в одну строку и главный экран со свайпом. В поиске App Store видно только первые кадры, поэтому самое важное — в начале.
  2. Одна функция — один кадр. Свайп, взаимная симпатия, чат, просмотры профиля, тёмная тема. Заголовок называет пользу, подзаголовок поясняет её.
  3. Цвет держит серию. Кадры чередуются между фирменным красным и сливовым градиентом из онбординга, светлый и раздвоенный кадры дают паузу. В ленте набор читается как одна история.
  4. Живые экраны вместо коллажей. В рамке настоящий интерфейс приложения; поверх — только то, что помогает прочитать сценарий: сообщение в чате, сердечки из онбординга.

Экраны приложения

Сплэш и онбординг из самого приложения — из них взяты цвета, сердечки и тон текстов для скриншотов.
